# Stockfy

Sistema local web de controle de estoque desenvolvido em PHP e MySQL.

# Funcionalidades

- Login de usuários
- Cadastro de produtos
- Controle de entrada e saída de estoque
- Dashboard com métricas
- Consulta de produtos
- Busca dinâmica
- Alerta de estoque baixo (em desenvolvimento)

# Tecnologias

- PHP
- MySQL
- HTML
- CSS
- JavaScript
